## Research findings

**1. world-globe pattern (to replicate):** `#[Computed(persist: true)]` + `Cache::rememberForever("maps.<key>.<version>.{locale}")`; dataset injected as JSON keyed by geodata id; ready-to-display tooltip strings built in PHP (`__('globe.companies_count', ...)`) because amCharts templates can't run `__()`; list FIRST in DOM (real `<a>` links, `wire:key`, `data-*` hooks); canvas `wire:ignore` inside `dir="ltr"` wrapper; plain inline IIFE `<script>` (never `@script` — second-root crash); `whenGlobalsReady` guard with silent `collapseCanvas()` fallback; base series (neutral, `interactive: false`) + active series (`include: keys(dataset)`, accent fill, hover state, pointer cursor, `tooltipText` with PHP-built strings); click handler on active-series template with unconditional `preventDefault/stopPropagation`; list hover/click highlights+focuses map; teardown via `alpine:navigating` + `Livewire.hook('morph.removed')` → `root.dispose()`; init guard `dataset.vvXInitialized`. Colors: base 0xE9EEF3, stroke 0xFFFFFF, accent 0xD97440, hover 0x0F4C81.

**2. Schema:** `states`: id, country_id (FK), name/type (json translatable), slug (unique), `code string(10)` (indexed, NOT unique), lat/lon decimal nullable, is_active, softDeletes. `countries.iso2` ('IR') is the world-globe join key — states have **no** geodata key today. Iran = Country with `iso2='IR'`.

**3. Placeholder:** ⚡country.blade.php lines 61–66 — the `card` with `<!-- country map -->` comment; component goes there (wrapped so it only renders when config exists).

**4. Route:** `companies.state` = GET `/countries/{country}/{state}` → `pages::company-state`; params: `['country' => $country->slug, 'state' => $state->slug]`.

**5. Landing layout includes:** plain `<script src>` tags at landing.blade.php:917–926 — worldLow.js, usaLow.js etc. as global-var files after map.js/Animated.js. iranLow.js gets one identical line after worldLow.js.

**6. iranLow.js ids (fetched from cdn.amcharts.com — authoritative):** ids are official **ISO 3166-2:IR** codes `IR-01`…`IR-32` with **no IR-09** (31 features). Critically they do NOT match the seeder's `code` values everywhere (seeder uses national statistical numbering: seeder `05`=Alborz, but ISO `IR-05`=Ilam, `IR-32`=Alborz; same drift for Bushehr/Tehran/Chaharmahal/Semnan/Qom/Qazvin/Kerman etc.). So `geo_id` is genuinely needed; exact mapping (slug → geo_id), 31 entries: east-azerbaijan→IR-01, west-azerbaijan→IR-02, ardabil→IR-03, isfahan→IR-04, ilam→IR-05, bushehr→IR-06, tehran→IR-07, chaharmahal-and-bakhtiari→IR-08, khuzestan→IR-10, zanjan→IR-11, semnan→IR-12, sistan-and-baluchestan→IR-13, fars→IR-14, kerman→IR-15, kurdistan→IR-16, kermanshah→IR-17, kohgiluyeh-and-boyer-ahmad→IR-18, gilan→IR-19, mazandaran→IR-21, markazi→IR-22, hormozgan→IR-23, hamadan→IR-24, yazd→IR-25, lorestan→IR-20, north-khorasan→IR-31, razavi-khorasan→IR-30, south-khorasan→IR-29, golestan→IR-27, qom→IR-26, qazvin→IR-28, alborz→IR-32.

**7. Lang key:** `globe.companies_count` (`':count companies'`) already exists in all five locale files — **reuse it, no new key**.

## Implementation plan (after approval)

1. **Migration** `add_geo_id_to_states_table`: nullable `string('geo_id')` after `code`, indexed (non-unique — harmless duplicates across countries conceivable). No model $fillable-style attribute change needed beyond adding `'geo_id'` to State's `#[Fillable]`. **Do not run artisan migrate** — you run it.

2. **StateSeeder:** add `'geo_id' => 'IR-xx'` per province using the exact table above (values read from iranLow.js, not guessed).

3. **Geodata asset:** download iranLow.js → `public/theme/1/plugins/custom/amcharts/iranLow.js`; add `<script src>` in landing.blade.php after worldLow.js (line ~923).

4. **config/geo_maps.php:** `return ['countries' => ['iran' => 'iranLow']];` — country slug → geodata global suffix (`am5geodata_` + value). Future country = 1 config line + script + geo_id data.

5. **⚡country-map.blade.php** (maps/ namespace), generic over config:
   - Props: `Country $countryModel`; `#[Computed(persist:true)]` + `Cache::rememberForever("maps.country-map.{$countryModel->slug}.v1.{locale}")` producing state list for the page: only active states with ≥1 active `CompanyPublication` (same join pattern as world-globe), each `{geo_id, slug, name, url (route('companies.state',...)), count, count_text}` — plus full state count for the section copy.
   - Mount checks `config('geo_maps.countries.' . $countryModel->slug)`; ⚡country.blade.php renders the component only when that key exists (replacing the placeholder card) — absent key = no map, no error.
   - View mirrors world-globe: section root `.vv-globe-section` with heading/sub; `.vv-globe-layout` with **list first** (`.vv-globe-list`, `.vv-globe-link` + `data-geo`, count via `globe.companies_count`), then `.vv-globe-canvas-wrapper` > `#country-map-{id}` `wire:ignore`.
   - Inline IIFE script: same `whenGlobalsReady`/`collapseCanvas`/init-guard/teardown scaffolding; globals check includes `am5geodata_iranLow` (resolved from config via @json). **Static projection** (`geoMercator`), `panX/panY: 'translateX/translateY'` — no rotation; on init compute the country's geo-bounds from the geodata features and call `chart.zoomToGeoBounds(...)` (API verified in bundled map.js) to frame Iran.
   - Base series = all provinces neutral non-interactive; active series = `include: Object.keys(dataset)`, accent fill, hover state, pointer, `tooltipText: '[bold]{name}[/]\n{count_text}'`; click → navigate `url`. List hover/click → highlight polygon + zoom to that polygon's bounds (no navigation); list link itself stays a real anchor (middle-click/no-JS works — click handler only `preventDefault`s when map is alive, mirroring world-globe's focus behavior).
   - Reduced-motion: skip the zoom animation.

6. **Dark mode:** new `[data-bs-theme=dark]` block in app.css under a `maps/⚡country-map` comment — reuses the same remap pattern (canvas wrapper/link surfaces → `--bs-*`); **no changes** to the existing world-globe block.

**Constraints honoured:** no artisan migrate, no build/test commands; world-globe untouched; app.css gets only the new component's block; public/theme/1 gets only the added iranLow.js; no new lang keys (reuse `globe.companies_count`).
